# Blog Preview Card

A clean, modern blog preview card component built with semantic HTML and custom CSS. This project focuses on mastering the CSS Box Model, custom font integration, and the "Neo-brutalism" design style.

## 🚀 Features
- **Responsive Design**: Optimized for both mobile and desktop screens.
- **Custom Fonts**: Integrated the "Figtree" font family locally for high-quality typography.
- **Neo-brutalism Style**: Features a distinct hard-shadow effect (`box-shadow`) and bold borders.
- **Hover States**: Interactive title with color transitions.

## 🛠️ Built With
- **HTML5**: Semantic markup for better accessibility.
- **CSS3**: Custom properties, Flexbox for centering, and advanced positioning.
- **Local Assets**: Managed fonts and images within the project directory.
